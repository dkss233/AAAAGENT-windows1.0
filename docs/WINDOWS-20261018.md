# Windows 更新：QQ 机器人与桌宠记忆整合

发布日期：2026-10-18（北京时间）

Windows 独立源码在 0.3.0-dev.1 基线上接入新的角色社交与记忆模块。这次让现有 QQ 机器人的真实交流进入桌宠可引用的社交经历，同时保留原有私人记忆、云端对话和工程工作台。

## 这次更新了什么

- **QQ 的实际交流进入社交记忆。** 取得平台回复回执后才入队，根据已经发出的回复生成摘要；持久队列和幂等事件用于断线重试，不重复发 QQ 回复。
- **桌宠知道角色在群里经历了什么。** 每 15 秒同步允许共享的摘要，保留群、成员、时间及来源；群友与主人分别归属，公开人设与私人角色设定分开。
- **共享可以撤回。** 关闭群共享或遗忘经历会撤回缓存及相关派生摘要；五分钟没有成功同步时，缓存停止参与新回答。
- **适配 Windows 长时后台运行。** 新增当前用户登录任务 `AAAAGENT-SocialMemory-Local`、进程退出恢复及 `start / stop / restart / status` 管理命令；当前实现依赖用户登录。
- **配置沿用 Windows 权限边界。** 服务配置、数据库与连接凭据由 SID ACL 保护，云端模型密钥引用已有受保护文件。QQ 管理进程与社交服务分别管理。
- **更新项目首页。** 完整项目架构图放在中英文首页最上方，补充桌面宿主、模型、私人记忆、社交缓存、QQ 检索和 T3 / Flow 工作台的关系及代码入口。
- **独立检查社交接线。** 增加 `npm.cmd run test:social`，用于运行 27 项社交、缓存、回执与公开包检查。

本次是开发版源码更新。现有 QQ 迁移包需已完成账号配置；本仓库提供渠道适配器、Runtime 接线补丁及检查脚本，不包含完整 QQ 运行包、私人凭据、模型权重或角色媒体。

本次没有重新测试本地模型质量、实体音频设备、完整 Mac 原生宿主或长期连续负载。之前 Windows 本地 4B 对话与后台记忆的已知失败继续见 [历史验证](WINDOWS-20261010.md)和[本地 LLM](LOCAL-LLM.md)。

## 安装与运行

保留自己的 `.local/`、外部凭据、账号与授权素材，先按 [Windows 安装与升级](../README-WINDOWS.md)构建和登记匹配运行版本。现有 QQ 迁移包的布局、适配器安装、后台服务启停及群共享设置见 [Windows 社交记忆](SOCIAL_MEMORY.md)。启动顺序为社交服务、QQ 机器人、桌宠。
