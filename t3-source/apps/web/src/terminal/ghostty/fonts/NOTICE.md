# Symbols Nerd Font Mono provenance

The locally imported `SymbolsNerdFontMono-Regular.woff2` identifies itself as **Nerd Fonts 3.4.0**. The source font directory's [MIT license](https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/patched-fonts/NerdFontsSymbolsOnly/LICENSE), retained here as `LICENSE`, credits Ryan L McIntyre.

The font also merges glyphs from other projects. Nerd Fonts' [3.4.0 license audit](https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/license-audit.md) identifies CC BY 4.0, Apache-2.0 and OFL sources, and lists **Font Logos as Unlicensed**. Read-only inspection of this local WOFF2 found 10,410 character mappings, including the Font Logos range with glyphs such as `linux-apple`, `linux-alpine` and `linux-archlinux`.

This AAAAGENT source release omits the merged WOFF2 rather than treating the directory MIT file as a separate grant for every incorporated icon. Keep this notice and the original MIT file to explain the optional resource's provenance. Users who supply a symbol font separately must check its complete component licenses and attribution requirements; this notice grants no additional rights to the incorporated glyphs or brand marks.
