========================================================================
  AAAAGENT 桌宠 · 使用说明
========================================================================

【一、日常使用】

  启动桌宠：双击  启动桌宠.cmd
  （启动器会打印进度，就绪后显示「✅ 桌宠已就绪」并自动关闭；
    不会弹出 cmd 窗口，桌宠在后台运行）

  退出桌宠：点桌宠面板上的退出按钮，或关闭桌宠窗口。
  （退出时会自动停止桌宠启动的 Harness 主机，释放内存）

  控制台（改设置、看状态）：
  启动桌宠后，命令行窗口里会打印一行「控制台: http://127.0.0.1:xxxxx/#token=...」
  把整行地址复制到浏览器打开即可。
  也可以从桌宠面板上的「控制台」按钮进入。

  桌宠右侧的三个圆形按钮（从上到下）：

    🔒  锁定鼠标穿透
        开启后鼠标点击会落到下方窗口；把鼠标移回这个按钮上即可解锁。

    ✥   调整模型
        开启后可用滚轮缩放模型、拖动平移模型。
        长按此按钮可重置模型位置和大小。

    👁  注视鼠标
        开启后模型的眼睛、头部和身体会一起跟随鼠标，
        鼠标移出桌宠窗口后仍然继续跟随。
        再点一次关闭，模型回到静止姿态。

【二、换模型】

  双击  更换模型.cmd
  （或  选择模型并更换.cmd  —— 效果一样，都会弹出文件夹选择窗口）

  操作：
    1. 在弹出的窗口里选到模型文件夹
       （如果里面还套了一层同名文件夹，程序会自动进入，不用手动点进去）
    2. 看到检查结果后，按提示确认安装
    3. 等它自动完成：安装 → 重建 → 重新固定指纹
    4. 重启桌宠（先退出，再双击 启动桌宠.cmd）

  程序会自动处理这些情况：
    · 模型文件夹外多套一层同名文件夹      → 自动进入
    · 模型缺少表情声明（VTS 导出的常见问题）→ 自动补全
    · 换模型后需要重建渲染器              → 自动重建
    · 换模型后需要重新固定指纹            → 自动完成

  换模型后需要重新设置的部分：
    · 情绪映射和「持续启用」会被清空（因为模型换了，条目对不上了）
    · 需要回控制台的「表情与动作」页重新设置


========================================================================
【三、表情与情绪】

  位置：控制台 →「表情与动作」

  桌宠的表情由「助手这一轮回复的情绪」决定，不是由你输入的情绪决定。
  所以要让桌宠做出某个表情，要说能引出它情绪的话，而不是命令它。

  每张表情卡片上有两个控件：

    ① 对应情绪  —— 下拉框，选这个表情对应哪种情绪
       可选：开心 / 悲伤 / 温柔 / 生气 / 惊讶
       一个情绪只能配一个表情；配到新的表情会自动从旧的那里移过来。

    ② 是否持续启用该表情  —— 勾选框
       勾上后，桌宠会一直保持这个表情的效果。
       典型用途：作者署名的「水印」表情 —— 持续启用后水印就不再显示。
       取消勾选即可恢复。

  卡片上还会显示该表情影响哪些模型参数，便于判断效果是否明显。

  建议：
    · 把「开心」配到外观变化明显的表情（例如「外套」「爱心眼」），便于确认效果
    · 「水印」「翅膀消失」这类是外观开关，适合用「持续启用」


========================================================================
【四、什么时候需要"重新固定指纹"】

  指纹 = 一份记录程序文件哈希的清单，启动时校验，保证跑的是验收过的版本。

  需要重新固定：
    · 修改程序代码后
    · 换模型后（换模型工具会自动完成这一步）

  不需要重新固定：
    · 改情绪映射、持续启用等控制台设置（存在别处，立即生效）

  你日常使用（换模型、改设置）都不需要手动跑这条命令。
  「更换模型.cmd」会帮你自动完成。

【五、常见问题】

  Q: 双击 .cmd 文件没反应或窗口一闪而过？
  A: 早期版本的批处理文件用了 LF 换行，cmd.exe 无法解析。已修复为 CRLF。
     如果又出现，告诉我。

  Q: 启动时提示「试用程序文件缺失或已变化」？
  A: 程序文件被改动过但没重新固定。在
       D:\AAAAGENT\windows\code\desktop-pet
     目录里执行：
       node tools\repin-config.mjs --activate
     然后重启桌宠。

  Q: 换了模型后控制台报「只能隐藏本模型的预设条目」？
  A: 旧设置里残留了上一个模型的条目。已修复为启动时自动丢弃失效设置。
     如果仍出现，重启一次桌宠即可。

  Q: 情绪映射配好了，但桌宠表情没变化？
  A: 检查三件事：
     1. 该情绪对应的表情是否在「允许自动使用」范围内
     2. 对话时助手是否真的用了那个情绪（说能引出情绪的话）
     3. 该表情在模型上是否足够明显（换「外套」这类明显的试）

  Q: 后台有个 npm start 的 cmd 窗口？
  A: 那是桌宠的启动链（桌宠后端由它启动），最小化在任务栏。不要关闭它。

  Q: 控制台「记忆与对话」里的当前情绪显示「暂无」？
  A: 那是长期情绪状态管线，本试用配置未启用，与表情功能无关。

【六、Harness 主机（按需启动）】

  桌宠的对话、语音、表情都不需要 Harness 主机，所以它默认【不启动】。
  Harness 主机约占 400+ MB 内存，只有让桌宠执行 DSH 任务时才需要。

  三种启动方式（任选其一）：

    1. 控制台 →「任务转发」页 → 点【启动 Harness】按钮
       （约 3 秒就绪，状态会自动刷新）

    2. 双击  启动Harness.cmd

    3. 直接下达 DSH 任务（例如"使用harness查看工作区目录"）
       主机会在确认执行时自动启动

  查看状态：控制台「任务转发」页会显示 Harness 是否就绪。
  状态显示"不可用"是正常的 —— 表示主机还没启动，不是故障。

  退出桌宠时：
    · 桌宠会【自动停止它自己启动的】Harness 主机，释放约 400+ MB 内存
    · 但用 启动Harness.cmd 单独启动的主机不会被动 —— 那属于你的手动操作
    · 想让主机一直留着（方便反复使用），设置环境变量
        AAAAGENT_KEEP_HARNESS=1
      再启动桌宠即可
