========================================================================
  Live2D 表情与情绪映射 —— 说明
========================================================================

【★ 现在不需要手工改文件 ★】

  控制台的「表情与动作」页面已经支持直接操作，改完立即生效，
  不需要重新构建、不需要重新固定指纹、不需要重启桌宠。

    · 情绪映射
        在「表情与动作」页里，为每个情绪指定一个表情。
        一个情绪对应一个表情；改配到新的表情会自动从旧的那里移过来。

    · 是否持续启用该表情
        勾上后该表情的效果常驻。
        适用于"外观开关"型的表情 —— 例如模型作者署名用的标记类表情。

    · 预览
        预览面板下方有缩放滑块（0.2×–8×），便于看清模型细节。

  完整的界面说明见同目录的《使用说明.txt》。


========================================================================
【什么时候还需要手工改】
========================================================================
  仅在以下情况才需要直接编辑预设文件：

    · 控制台打不开
    · 需要批量修改很多条目
    · 需要在桌宠启动前就准备好配置

  手工修改的对象是模型自己的预设文件，其中的条目由导入工具生成：

    <项目根>\code\desktop-pet\desktop\assets\<模型目录>\presets.json

  ★ 不要手改 desktop\assets\jellyfish\ 下的副本 —— 它是构建时同步的镜像。


========================================================================
【条目字段的含义】
========================================================================
  要让一个表情被自动使用，条目需要有这三条信息：

      "availability": "automatic"     ← 允许自动使用
      "emotions": ["happy"]           ← 挂到哪种情绪（可多个）
      "expressionName": "<表情名>"     ← 必须与模型里的表情名完全一致

  ★ 缺少这三条的条目只能在控制台里手动预览，运行时不会被自动使用。

  注意：expressionName 必须填**你自己模型里的真实表情名**。
  不同模型的表情名各不相同，请以导入后 presets.json 里生成的内容为准。


========================================================================
【可用的情绪值】
========================================================================
  必须从这 6 个里选，写错会被当成 neutral：

      neutral      中性（默认，不触发表情）
      happy        开心
      sad          悲伤
      warm         温柔 / 温暖 / 安慰
      angry        生气
      surprised    惊讶

  一个表情可以挂多个情绪，例如： "emotions": ["happy", "surprised"]


========================================================================
【改完之后必须做的两步】
========================================================================
  打开 PowerShell，依次执行：

      cd <项目根>\code\desktop-pet
      npm run build:desktop
      node tools\repin-config.mjs --activate

  原因：presets.json 会被"烘焙"进渲染器（desktop\build\renderer.js），
        不重新构建的话桌宠读到的还是旧配置。

  然后重启桌宠（双击 启动桌宠.cmd）。


========================================================================
【改前建议备份】
========================================================================
  复制 presets.json 到项目外任意位置留底即可。


========================================================================
【注意点】
========================================================================
  · 文件必须保存为 UTF-8 **无 BOM**，否则解析会失败。
    推荐用 VS Code 保存。

  · 字段名用连字符写法（"modelFingerprint"）—— JSON 里不能用下划线。

  · 不要手改 modelFingerprint —— 它是模型内容的校验值。
    改了它、或改了模型文件，桌宠会报「模型与预设目录版本不一致」并拒绝加载。
    更换模型后应让换模型工具重新生成，而不是手工编辑。
========================================================================
